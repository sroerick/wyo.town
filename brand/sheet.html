§6

Use

Always

  1. The desert is the subject. The machine is the medium.
  2. Number the thing before you name it.
  3. One field per page, one accent per page.
  4. A tile beside content, never behind it.
  5. Rules, not shadows.
  6. Band a gradient. Dither a boundary.
  7. Date everything.

Never

  1. Blending gradients, glow, glass, soft shadow.
  2. A repeating background.
  3. The mark rotated, animated or winking.
  4. A color invented for one page.
  5. A fifth typeface.
